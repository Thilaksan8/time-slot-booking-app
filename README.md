# 📅 Time Slot Booking System

A full-stack MERN (MongoDB, Express.js, React, Node.js) application for managing appointment bookings with CRUD functionality.

---

## ✨ Features

- Create a booking
- View all bookings
- Update an existing booking
- Delete a booking
- Prevent duplicate time-slot bookings
- Dynamic time slot availability
- Responsive user interface
- MongoDB Atlas integration

---

## 🛠 Tech Stack

### Frontend

- React
- Vite
- CSS

### Backend

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
